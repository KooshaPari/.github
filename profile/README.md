## 🧩 Architecture

```
PhenoShared (core)
├── 459 composable crates
├── Feature-gated optional modules
├── Bounded APIs, minimal dependency closures
└── "Polyrepo-in-repo" pattern

PhenoApps (shelf)
├── Archived projects (reference only)
├── Sunset tools & experiments
└── Historical preservation

.github (templates)
├── Reusable CI workflows
├── Issue & PR templates
├── Org profile & community health
└── Default governance files
```

## 🎯 Principles

- **Compose over monolith** — Feature-gated crates with bounded APIs
- **Dynamic coupling** — Minimal dependency closures
- **Polyrepo-in-repo** — Each crate is independently testable
- **Reuse existing capability** — Over parallel implementation
- **Evidence-driven** — Forensic analysis before any merge
